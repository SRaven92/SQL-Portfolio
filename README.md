# SQL Portfolio

This repository contains SQL projects demonstrating my work with relational databases, data analysis and practical problem solving.

My projects focus on using SQL to structure, query and analyse data, with an emphasis on practical applications that relate to real-world problems.

## Projects

### 🏗️ Construction Compliance Tracker

A relational database designed around regulatory compliance within the construction industry, based on the type of project and compliance information I work with professionally.

The database brings together information on:

- Projects
- Duty holders
- Compliance reviews

The project demonstrates relational database design, primary and foreign keys, joins, functions, queries and stored procedures.

It was developed using SQL and DBeaver with synthetic test data, allowing compliance information to be queried across multiple projects and review items requiring attention to be identified.

➡️ See the `Compliance-Tracker` project for the full database structure, SQL queries and project README.
